## Frozen contracts

### `PendingTransferLedger<TKey>` (owns: Agent A, `src/CardShopCoop/Sync/PendingTransferLedger.cs`)
```csharp
internal struct PendingTransfer<TKey>
{
    public uint Seq;
    public TKey Target;
    public int RequestedDelta;
    public int TransferType;   // local EItemType id
    public int EscrowToken;    // > 0 for a take, 0 for an add
    public float FirstSentAt;
    public float LastSentAt;
    public int Attempts;
    public bool Escalated;
}

internal sealed class PendingTransferLedger<TKey>
{
    public const float ResendIntervalSeconds = 1.0f;
    public const int EscalateAttempts = 15;   // log + force resync; keep entry
    public const int HardAttempts = 60;        // stop retransmitting; KEEP entry + obligation
    public const int MaxOutstanding = 256;

    public Action<PendingTransfer<TKey>> Resend;   // module re-sends the SAME seq
    public Action<PendingTransfer<TKey>> Escalate; // module logs + requests resync; MUST NOT resolve

    public uint Begin(TKey target, int requestedDelta, int transferType); // 0 => fail-closed, do not track
    public bool TryGet(uint seq, out PendingTransfer<TKey> entry);
    public bool TryResolve(uint seq, out PendingTransfer<TKey> entry);
    public bool IsAddReserved(TKey target);
    public void ResolveTake(in PendingTransfer<TKey> entry, int acceptedDelta);
    public void ReleaseAdd(TKey target);
    public void Tick();   // replaces Prune(); retransmits due entries; never drops
    public void Clear();
}
```
Rules: `Begin` with `requestedDelta < 0` and `ReserveTake` failure returns `0` and records nothing.
`Begin` with `_entries.Count >= MaxOutstanding` returns `0` (fail-closed, log error).
`Tick` retransmits entries whose `now - LastSentAt >= ResendIntervalSeconds` while
`Attempts < HardAttempts`; at `EscalateAttempts` invoke `Escalate`; at `HardAttempts` invoke
`Escalate` once (Escalated flag) and stop retransmitting, but KEEP the entry.
Entries are removed ONLY by `TryResolve` or `Clear`.

### `HandEscrow` (owns: Agent A, `src/CardShopCoop/Sync/HandEscrow.cs`)
Existing API kept: `ReserveTake(int localType, int count) -> int`, `ResolveTake(int token, int acceptedMagnitude)`,
`ExpireTake(int token)`, `IsReserved(Item)`, `HasReservedHeld(InteractionPlayerController)`,
`EscrowAdded(comp, type, count)`, `Tick()`, `Reset()`.
New API:
```csharp
public static void NoteTakenItem(Item item);      // client-only; immediate protection
public static void BeginSuppressNote();
public static void EndSuppressNote();
internal static bool IsNoteSuppressed { get; }
public static bool IsInLocalHand(Item item);
```
Semantics: `NoteTakenItem` records the exact returned `Item` in a per-type recent-takes map and
counts as reserved immediately. `ReserveTake` consumes matching noted items first, then falls back
to a hand scan; only a complete match yields a token. `IsReserved` returns true for noted items too.
Notes are pruned when the item is destroyed, not in the local hand after a short grace, or older
than the reserve TTL (then force a resync and log loud). Suppress-note wraps internal
`TakeItemToHand` drains (`HandEscrow.EscrowAdded`, `ItemBoxFamily.ApplyContent`).
